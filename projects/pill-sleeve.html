Pill Adherence Sleeve

A sleeve around a pill bottle that records removal-and-return cycles and makes the day’s count visible through a simple LED display.

Use the action that already happens

The bottle sits inside the sleeve. An infrared break-beam sensor detects when it is removed and returned; a completed cycle increments the counter. There is no app to open or separate log to remember.

An eight-pixel display shows the state: red before any cycles have been recorded, green for the count, and a blue sweep while the bottle is out.

Designing for ordinary mistakes

Picking up the bottle to read its label can create an accidental count. That made an undo button more useful than an add button. Presses while the bottle is out are ignored, and sensor readings are debounced to avoid treating a brief interruption as a real event.

The device uses wall power so daily charging is not part of the routine. An RTC keeps the clock running through an outage, while the stored count can survive a loss of main power. Optional Wi-Fi is used for clock synchronization and settings; the core device operates offline.

A housing shaped by assembly

The enclosure is generated parametrically and includes sensor pockets, a display window, board supports, and a separate base plate. Iterations widened the bottle opening, increased room for the electronics, and replaced a cable hole that was too small for the actual USB connector.

Physical button mounting remains an open assembly detail. The project is still being tested, with diagnostic output retained to understand timing and reset behavior.

Making the state understandable

The design includes a daily reset, adjustable settings, and visual feedback when a configured target is reached. The display and correction mechanism are as much a part of the product as the sensor and firmware.

The device records bottle-use events as a proxy for doses. It cannot verify that medication was swallowed or that the correct amount was taken.
